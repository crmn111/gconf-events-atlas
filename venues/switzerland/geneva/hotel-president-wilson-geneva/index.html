About

Official HotellerieSuisse member directory classifies Hôtel President Wilson, Quai Wilson 47, 1201 Genève, as a 5 Star Superior Hotel. Superior is an add-on within the five-star category, not a sixth star. Official Marriott events schema: WILSON Room maximumAttendeeCapacity 1,000 and 9,676.8 sq ft (899 m²). Official Marriott address block uses postal code 1211; the official classification listing uses 1201 Genève, which is stored.
